# Mudae BR para Android

App oficial do [Mudae BR](https://mudaebr.com.br) para celulares Android.

## Como instalar

1. Abra **Releases**, ao lado, e baixe o arquivo `.apk` da versão mais nova.
2. Abra o arquivo no celular. Se o Android pedir, permita instalar apps desta fonte.
3. Pronto. As próximas versões aparecem dentro do próprio app.

Baixe só por aqui ou pelo link oficial no Discord do Mudae BR. Cada versão traz o código SHA-256 do arquivo, para quem quiser conferir.

Este repositório guarda só os lançamentos do app; o código não fica aqui.
